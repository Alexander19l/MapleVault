# 1.0.18 · Almacenamiento offline testeable

Refactor con un objetivo concreto: hacer testeable la lógica que antes vivía dentro de `main.ts`.

## Cambios

- La lógica de ZIP, rutas, enumeración y lectura se aisló en
  `app/desktop/electron/mangaOfflineStorage.ts`.
- `main.ts` solo resuelve la carpeta de Descargas y conecta los mismos canales IPC. **No cambia
  el contrato del preload ni de React.**
- La enumeración recorre subcarpetas internas del ZIP, acepta solo imágenes permitidas y conserva
  orden numérico estable.
- Se mantienen los límites de 500 páginas y 256 MiB, más validación contra traversal antes de
  escribir cada entrada.
- Los ZIP inválidos se rechazan **antes** de crear la carpeta de descarga.

## Por qué importa

Es el único módulo de la capa Electron con cobertura real de tests. El resto —`main.ts`,
`preload.ts`, `launcher.ts`, `adblock/*`— sigue sin ninguna →
[[DEUDA-desktop-sin-tests]]. Este refactor es el patrón a repetir: extraer la lógica pura del
proceso principal para poder probarla desde vitest.
