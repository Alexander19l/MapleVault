# 1.0.17 · Carga paginada del lector offline

Sustituye la devolución del capítulo completo en base64 por carga bajo demanda.

## Cambios

- `manga-read-offline-chapter` acepta `offset` y `limit`, con tope de 12 páginas por llamada y
  máximo de 500 por capítulo.
- La respuesta incluye `total`, `offset` y `hasMore`, de modo que React conoce el tamaño real sin
  cargar todas las imágenes en memoria.
- `MangaReader` conserva las páginas ya cargadas y solicita solo la actual en modo página. El
  modo continuo pide las restantes únicamente si el usuario lo elige.
- La carpeta del capítulo se identifica primero por clave exacta y solo después por coincidencia
  parcial.
- La asociación entre capítulos y carpetas usa una expresión delimitada para que el capítulo `1`
  no se confunda con el `10`.

## Riesgos conocidos que siguen abiertos

- El modo continuo vuelve a consumir memoria proporcional al capítulo: debe reservarse para
  capítulos razonables.
- Si el usuario renombra carpetas descargadas a mano, la clave exacta deja de coincidir y solo
  funciona la compatibilidad parcial.
- **Falta medición real de memoria en Windows con un capítulo grande.**
